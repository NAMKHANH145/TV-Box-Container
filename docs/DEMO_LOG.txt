== 1. Chay mot lenh trong container ==
$ minicontainer run --rootfs ./rootfs /bin/sh -c "id -u; echo hello"

== 2. Web server chay nen: RAM 32M, CPU 20% ==
$ minicontainer run -d --name web --ram=32M --cpu=20 --net=host \
      --rootfs ./rootfs /bin/httpd -f -p 8080 -h /www
web
$ curl -s http://127.0.0.1:8080
